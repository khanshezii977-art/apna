SHEZII KHAN — LUXURY AUTOMOTIVE WEBSITE

Files:
- index.html: single-file responsive website
- assets/: locally bundled WebP automotive images

Deploy to Vercel:
1. Upload index.html and the entire assets folder to the root of a GitHub repository.
2. Import the repository at https://vercel.com/new
3. Choose Other / static site if asked. Leave build command and output directory blank.
4. Deploy.

Important:
- Images are bundled locally, so the site does not depend on Unsplash URLs at runtime.
- Vehicle names and photos are demonstration content. Confirm image/model matching and replace demo inventory before commercial use.
